🚀 Free Deployment on Render (512MB RAM)

This backend is optimized to use less than 120MB RAM so it runs smoothly on Render's free tier without crashing.

  • 1. Push this repository to your GitHub.
  • 2. On Render.com, click New > Web Service.
  • 3. Connect your repo and set Environment to Python or Docker.
  • 4. Add your free GEMINI_API_KEY or GROQ_API_KEY in Environment Variables.
